# 🚀 Crypto & Stock Dashboard

A beautiful, real-time cryptocurrency and stock tracking dashboard built with React, TypeScript, and Tailwind CSS.

![Dashboard Preview](https://img.shields.io/badge/Status-Live-success)
![React](https://img.shields.io/badge/React-18.3-blue)
![TypeScript](https://img.shields.io/badge/TypeScript-5.6-blue)
![Tailwind](https://img.shields.io/badge/Tailwind-4.0-cyan)

## ✨ Features

- **Real-time Price Tracking**: Live cryptocurrency prices with 30-second auto-refresh
- **Beautiful Dark UI**: Sleek glassmorphism design with gradient backgrounds
- **Interactive Charts**: 7-day price trend visualizations with Recharts
- **Market Statistics**: Quick overview of gainers, losers, and total assets
- **Responsive Design**: Perfect on desktop, tablet, and mobile devices
- **Price Animations**: Smooth animations for price changes
- **24h High/Low**: Track daily price ranges for each asset

## 🛠 Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS 4.0
- **Charts**: Recharts
- **API**: CoinGecko API (free, no API key required)
- **Build Tool**: Vite
- **Icons**: Lucide React

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🌐 API

This dashboard uses the [CoinGecko API](https://www.coingecko.com/api) to fetch cryptocurrency data:

- Market data for top 10 cryptocurrencies
- 7-day price history
- 24-hour price changes
- Market cap and volume data

No API key is required for basic usage!

## 🎨 Design Features

- **Glassmorphism**: Frosted glass effect on cards
- **Gradient Backgrounds**: Beautiful color transitions
- **Hover Effects**: Smooth scale and shadow animations
- **Color-coded Changes**: Green for gains, red for losses
- **Responsive Grid**: Adapts to any screen size
